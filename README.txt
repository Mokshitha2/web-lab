MOKSHITHA - CSE RESUME AND BIO-DATA WEBSITE

HOW TO OPEN
1. Extract this ZIP file to a folder.
2. Keep all files together in the same folder.
3. Double-click index.html to open the website in Chrome, Edge or another browser.
4. Use the Home, Resume and Bio-data links to move between pages.
5. On Resume or Bio-data, use "Print / Save as PDF" to save a PDF copy.

FILES
- index.html: Home page
- resume.html: Resume
- biodata.html: Bio-data
- style.css: Website design
- script.js: Small page script
- profile.jpg: Your profile photo

Your photo is included on all three pages. Update any details by editing the relevant HTML file.
